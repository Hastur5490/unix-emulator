# Эмулятор оболочки UNIX

Эмулятор командной оболочки UNIX-подобной ОС.  
Реализован в виде графического интерфейса (Tkinter).

## Этап 1. REPL

Минимальный прототип с поддержкой диалога с пользователем.

### Возможности

- Графический интерфейс
- Заголовок окна формируется на основе данных ОС (`username`)
- Парсер с раскрытием переменных окружения (`$USERPROFILE`, `$USERNAME` и т.д.)
- Команды-заглушки: `ls`, `cd`
- Команда `exit`
- Обработка ошибок (неизвестная команда, неверные аргументы)

### Запуск

run.bat

## Этап 2. Конфигурация

Эмулятор стал настраиваемым через параметры командной строки.

### Параметры запуска

  Параметр     Описание                          
  `--vfs`      Путь к физическому расположению VFS 
  `--script`   Путь к стартовому скрипту         

### Возможности Этапа 2

- Отладочный вывод всех параметров при запуске
- Выполнение стартового скрипта
- Скрипт останавливается при первой ошибке
- При выполнении скрипта отображается и ввод, и вывод

### Запуск

python src/main.py
python src/main.py --vfs C:\path\to\vfs --script test_script.txt

## Этап 3. VFS

Подключена виртуальная файловая система.

### Возможности Этапа 3

- VFS полностью хранится в памяти
- Источник VFS — CSV-файл
- Поддержка base64 для содержимого файлов
- Если путь к VFS не указан — создаётся VFS по умолчанию
- Обработка ошибок загрузки (файл не найден, неверный формат)

### Формат CSV

csv
path,type,content
/,dir,
/home,dir,
/home/user/readme.txt,file,Текст файла

Тестовые vfs
Файл,Описание
vfs/minimal.csv,Минимальная VFS
vfs/simple.csv,Несколько файлов и папок
vfs/deep.csv,Вложенность 3+ уровней

Запуск
python src/main.py
python src/main.py --vfs vfs/deep.csv
python src/main.py --vfs vfs/deep.csv --script test_all.txt

## Этап 4. Основные команды

Реализована настоящая логика работы с VFS.

### Новые и обновлённые команды

 Команда    Описание                                      
 `ls`       Показывает содержимое текущей директории VFS  
 `cd`       Меняет текущую директорию в VFS               
 `find`     Ищет пути в VFS                               
 `uname`    Выводит информацию о системе                  
 `rev`      Переворачивает переданные аргументы           

### Запуск теста Этапа 4
