# Эмулятор оболочки UNIX

Эмулятор командной оболочки UNIX-подобной ОС.  
Реализован в виде графического интерфейса (Tkinter).

## Этап 1. REPL

Минимальный прототип с поддержкой диалога с пользователем.

### Возможности

- Графический интерфейс
- Заголовок окна формируется на основе данных ОС (`username`)
- Парсер с раскрытием переменных окружения (`$USERPROFILE`, `$USERNAME` и т.д.)
- Команды-заглушки: `ls`, `cd`
- Команда `exit`
- Обработка ошибок (неизвестная команда, неверные аргументы)

### Запуск


run.bat

## Этап 2. Конфигурация

Эмулятор стал настраиваемым через параметры командной строки.

### Параметры запуска

  Параметр     Описание                          
  `--vfs`      Путь к физическому расположению VFS 
  `--script`   Путь к стартовому скрипту         

### Возможности Этапа 2

- Отладочный вывод всех параметров при запуске
- Выполнение стартового скрипта
- Скрипт останавливается при первой ошибке
- При выполнении скрипта отображается и ввод, и вывод

### Запуск

python src/main.py
python src/main.py --vfs C:\path\to\vfs --script test_script.txt
